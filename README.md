# GEA - Global Earthquakes Analytics

## Description
GEA is a visual analytics tool that integrates multiple techniques to gain insights into the seismic activity observed throughout the year 2023. GEA offers an interactive platform where users can analyze earthquake data across multiple dimensions. By transforming raw data into meaningful visualizations, GEA provides critical insights for a wide range of users, including seismologists, urban planners, policymakers, and emergency management professionals. The core features include a geographical map (which displays seismic events on a global map), a parallel coordinates plot (that visualizes relationships between various seismic attributes), a heatmap ( which presents seismic events across a timeline for temporal analysis), and a t-distributed Stochastic Neighbor Embedding (t-SNE) scatterplot to identify patterns, trends, and potential hidden relations associated with an earthquake event. Users, like seismologists and geophysicists, can interact with the system for a focused analysis and explore insights from them conducting in-depth research and forecasting. Its ability to integrate spatial, temporal, and multi-dimensional data into an easy-to-use platform makes it an essential resource for improving earthquake risk assessment, enhancing resilience in vulnerable regions, and ultimately contributing to safer communities worldwide.
